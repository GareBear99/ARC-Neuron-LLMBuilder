# ARC-Neuron MCP Layer

This folder contains a governed MCP scaffold for ARC-Neuron LLMBuilder.

It is intentionally policy-first:

- tool registry
- risk classes
- allowed/denied paths
- receipt schema
- sandbox-first writes
- approval flags for risky actions

The included Python files are starter scaffolds, not a full MCP server runtime yet. They establish the integration surface and safety model for the next implementation pass.
