# Sponsorship Program — ARC-Neuron LLMBuilder

**Sponsor link:** https://github.com/sponsors/GareBear99

ARC-Neuron LLMBuilder is a local-first AI infrastructure project. It focuses on governed model improvement, benchmark receipts, rollback lineage, CPU-first GGUF/llamafile runtime validation, token-level timeout-safe generation tracking, binary-first memory, ARC-StreamMemory, and sponsor-backed custom repository templates.

## Why Sponsor

Sponsors help turn the open-source foundation into a professional, documented, reproducible system that builders can understand, test, and extend without depending on cloud-only AI infrastructure.

## Sponsor Tiers

| Tier | Best fit | What it funds |
|---|---|---|
| Supporter | Users who want the project maintained | Docs, bug fixes, examples, release validation |
| Builder | Solo developers | Implementation notes, updates, issue visibility |
| Pro Builder | Serious builders | Repo templates, advanced setup notes, roadmap input |
| Studio / Small Team | Teams | Private checklists, template guidance, documentation priority |
| Enterprise / Custom Repository Sponsor | Organizations | Custom repo platform planning, onboarding notes, architecture support |

## Boundaries

Sponsorship supports development and documentation. It does not guarantee AGI, investment returns, or custom software delivery. Custom delivery requires a separate written agreement.


## Verification Surface

The sponsorship program is supported by:

- public CI: `.github/workflows/ci.yml`
- sponsor proof brief: `docs/SPONSOR_PROOF_BRIEF.md`

- enterprise readiness notes: `docs/ENTERPRISE_SPONSOR_READINESS.md`

Before pitching enterprise/custom-repository sponsorship as hardened, CI should be green and moderate-or-higher dependency alerts should be resolved or explicitly documented.
