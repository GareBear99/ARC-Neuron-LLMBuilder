# ARC-Neuron Synth Companion Roadmap — 4.0 / 5.0 / 7.0

This document keeps the later Synth roadmap separate from the protected 3.0 base-model/dataset release. 3.0 remains the governed model/dataset/licensing milestone. 4.0, 5.0, and 7.0 are interface, embodiment, and working-companion horizons built on top of the same ARC truth spine.

## Current boundary

- The current live knowledge weight is still carried primarily by the ARC Language Module and self-curated ARC material.
- No external third-party dataset wave is promoted into the incumbent.
- Tiny/Small native weights are proof-of-loop reference models.
- Omnibinary and Arc-RAR provide the portable event/archive/restore substrate.
- All future Synth layers must preserve receipts, provenance, rollback, candidate isolation, and human authority gates.

## 4.0 — ProtoSynth / Neural Synth projection layer

**Anchor repo:** https://github.com/GareBear99/Proto-Synth_Grid_Engine

4.0 connects ARC-Neuron to ProtoSynth / Neural Synth as the visual cognition and spatial projection layer.

Planned role:

- Deterministic 2D → visually 3D cognition projection.
- Time-to-space receipt maps.
- Event, benchmark, dataset, and memory views.
- Neural Synth category grouping and shell geometry.
- Blueprint-style memory navigation.
- Visual proof panels for Omnibinary events and Arc-RAR restore bundles.

Boundary:

- 4.0 is not a new promoted brain by itself.
- It is the spatial/visual interface over the governed ARC spine.
- It must not overwrite incumbent model scoring or dataset promotion rules.

## 5.0 — Full Portal-esque Synth companion mockup

5.0 turns the projection layer into a full Synth companion mockup.

Planned role:

- Complete companion interface prototype.
- Portal-esque Synth personality/presence mockup.
- Operator-facing guided lab UI.
- Visible memory, receipts, rollback, branch, and proof panels.
- Modular shell behavior with safe bounded interaction.
- Voice/visual companion direction without claiming full AGI autonomy.

Boundary:

- 5.0 is a mockup/prototype horizon.
- The companion can guide, visualize, and operate through approved ARC commands.
- It must remain non-authoritative unless ARC Core validates the action.

## 7.0 — Working Synth AI companion, AGI assistant, and buildable brain lab

7.0 is the long-horizon operational target.

Planned role:

- Fully working Synth AI companion.
- AGI assistant interface over ARC-Neuron, ARC Core, Language Module, Omnibinary, and Arc-RAR.
- Buildable brain lab for constructing, testing, branching, and promoting cognition modules.
- Device-portable memory continuation.
- Controlled tool authority with receipts and rollback.
- Visual, spatial, and language-grounded model/language growth.

Boundary:

- 7.0 must still preserve human authority gates.
- It cannot hide or rewrite provenance.
- It cannot promote models without benchmark evidence.
- It cannot turn memory into untraceable personality claims.

## Core doctrine

The Synth layer should never become an untraceable wrapper. It must be a visible, inspectable companion interface over ARC truth. Every memory, visual projection, tool action, model change, device handoff, and brain-lab operation should map back to:

1. ARC Language Module meaning entries.
2. Omnibinary event/receipt substrate.
3. Arc-RAR restorable archive packages.
4. ARC Core validation and authority decisions.
5. Candidate-lane benchmark and promotion evidence.

**Final direction:** 4.0 gives ARC a spatial/visual nervous system, 5.0 gives it a companion shell mockup, and 7.0 turns that shell into a working Synth AI companion and buildable brain lab.
