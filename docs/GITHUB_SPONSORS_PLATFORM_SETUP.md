## 60–90 Day Money Reality

GitHub Sponsors can be enabled quickly, but the practical financial timeline should be treated as a 60–90 day runway.

Planning assumptions:

- setup can happen immediately
- Stripe/GitHub verification can take time
- first sponsor funds may not feel operationally useful immediately
- real conversion depends on visible sponsor-only value
- v3.0 roadmap material should be the main conversion event

Do not market this as guaranteed income. Market it as a funding rail for serious ongoing development.
