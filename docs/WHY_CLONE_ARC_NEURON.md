# Why Clone ARC-Neuron LLMBuilder

Clone this repo if you want a local-first model-growth lab where training, benchmarking, promotion, rollback, and evidence are part of the same workflow.

## Try first

```bash
git clone https://github.com/GareBear99/ARC-Neuron-LLMBuilder.git
cd ARC-Neuron-LLMBuilder
python3 scripts/ops/demo_proof_workflow.py
```

## Why it is different

- governed promotion instead of blind overwrite
- incumbent and floor-model protection
- Omnibinary ledger and Arc-RAR rollback
- ARC Language Module as lexical/provenance spine
- dataset acquisition policy before external data touches weights
- ARC-StreamMemory add-on path for visual/video memory
- long-horizon Synth companion roadmap
