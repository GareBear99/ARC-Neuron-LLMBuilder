# Transitional License Notice for ARC-Neuron LLMBuilder Development

This notice documents the intended licensing posture for the development path toward ARC-Neuron/LLMBuilder 3.0.

## Historical releases

Prior public releases, including 1.0-era releases, remain governed by the license that accompanied those releases at the time they were published.

## Transitional development state

Development work between the 1.0-era codebase and the planned 3.0 full base-model release is transitional. During this period, code, datasets, manifests, candidate weights, and governance materials may be reorganized, isolated, or reclassified before the protected 3.0 release.

## Planned 3.0 release posture

ARC-Neuron/LLMBuilder 3.0 is intended to use a more protective license suitable for a full base-model/product release. The 3.0 license should address:

- source redistribution,
- trained weights,
- fine-tuned derivatives,
- dataset manifests,
- candidate artifacts,
- commercial resale,
- SaaS wrapping,
- model repackaging,
- brand/name use,
- benchmark/report misuse.

## Practical rule

Do not treat transitional development artifacts as a final commercial grant for unrestricted resale or repackaging. Final allowed uses for 3.0 should be determined by the 3.0 license package.
