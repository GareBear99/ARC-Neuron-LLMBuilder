# arc_neuron_base

ARC-Core repo reasoning SFT — 136 rows (`arc_neuron_base_sft.jsonl`).

Records summarise the strongest operating lessons from ARC-Core audit
documents (ARC-Console AUDIT_REPORT_v2.md and friends) for ARC-Neuron
Base. Schema: `{id, task_type, source_repo, input: {instruction, context},
...}` — see the first row of the file. Self-curated ARC data (our own
data), read by the native trainer (`collect_sft_corpus` in
`scripts/training/train_arc_native_candidate.py`).

- **Role:** training (native trainer). **Lane:** candidate_v2 (default for
  new dataset families). **Touches progression:** no — datasets never touch
  the progression; they are externally tested and documented.
- **Manifest:** `manifest.json` (generated by
  `scripts/ops/catalogue_datasets.py` — row counts, file SHA-256s, schema).
- **Master catalogue:** `datasets/README.md` / `datasets/CATALOGUE.json`.
