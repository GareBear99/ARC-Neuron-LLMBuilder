# arc_neuron_small

ARC-Neuron Small SFT + next-token text.

- `arc_neuron_small_sft.jsonl` — 240 rows, chat-style
  `{messages: [{role, content}]}` records (system: "You are ARC-Neuron
  Small, a governed local reasoning model inside the ARC stack").
- `arc_neuron_small_next_token.txt` — 13,723 lines of next-token text.

Self-curated ARC data (our own data), read by the native trainer
(`collect_sft_corpus`).

- **Role:** training (native trainer). **Lane:** candidate_v2.
  **Touches progression:** no.
- **Manifest:** `manifest.json` (generated by
  `scripts/ops/catalogue_datasets.py`).
- **Master catalogue:** `datasets/README.md` / `datasets/CATALOGUE.json`.
