# distillation_eval

Distillation eval seed tasks — 45 rows (`seed_tasks.jsonl`).

Rubric-scored eval tasks (`{id, capability, prompt, reference: {rubric},
scoring, tags}`). These are EVALUATION tasks, not training input — they
measure whether a candidate preserves constraints, critiques weak
assumptions, and stays bounded.

- **Role:** evaluation. **Lane:** candidate_v2. **Touches progression:** no.
- **Manifest:** `manifest.json` (generated by
  `scripts/ops/catalogue_datasets.py`).
- **Master catalogue:** `datasets/README.md` / `datasets/CATALOGUE.json`.
